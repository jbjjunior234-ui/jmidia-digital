# JMidia Digital — site institucional

Site estático responsivo em HTML, CSS e JavaScript, pronto para GitHub Pages.

## Visualizar localmente

Abra `index.html` em um navegador. Não é necessário instalar dependências.

## Publicar no GitHub Pages

1. Entre em https://github.com e crie um repositório público chamado `jmidia-digital`.
2. Faça upload de `index.html`, `styles.css`, `script.js` e `favicon.svg` **na raiz** do repositório (o README é opcional).
3. Confirme o upload com **Commit changes**.
4. Acesse **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**.
6. Escolha a branch `main` e a pasta `/(root)`, depois clique em **Save**.
7. Aguarde a publicação. O endereço será `https://SEU-USUARIO.github.io/jmidia-digital/`.

## Personalização

- As cores ficam no início de `styles.css`, em `:root`.
- Textos e seções ficam em `index.html`.
- A marca gráfica atual é tipográfica/provisória. Substitua-a pela logomarca oficial quando disponível.
- O portfólio contém exemplos **conceituais**, não trabalhos reais.
- Não há formulário que armazene dados nem backend; o contato ocorre via links externos.
